# Hong Kong Temperature and Humidity Analysis

使用香港过去约 50 年（1970–2020）的气象数据，分析日均气温与相对湿度之间的关系。

## 数据来源

[Kaggle - Hong Kong Weather](https://www.kaggle.com/datasets/hindy51/hong-kong-weather-20082016)，由香港气象局提供。

## 分析步骤

1. 读取 `weather.csv`，选择 `mean_temp`（日均气温）和 `RH`（相对湿度）两列
2. 数据清洗：转数值、去空值，检查数据范围是否合理
3. 绘制散点图，观察温度和湿度的分布
4. 建立简单线性回归模型，手动实现最小二乘法拟合
5. 计算 R² 和相关系数，评估模型效果

## 主要发现

- 数据量：18,262 条日记录
- 平均气温：23.3°C（范围 4.9°C ~ 32.4°C）
- 平均湿度：78.1%（范围 24% ~ 99%）
- **R² = 0.067**，温度和湿度之间没有显著的线性关系

## 低 R² 的可能原因

- 湿度受多种因素影响（降水、季风、海陆位置等），温度只是其中之一
- 可能存在非线性关系
- 不同季节和天气模式的数据混杂在一起
- 数据跨度超过 50 年，气候变化增加了噪声
